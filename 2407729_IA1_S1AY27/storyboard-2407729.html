C. Typography & Root Rules

  • Heading Font Family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif

  • Root Font Weight: 400 (Regular)
  • Heading Font Weight: 600 (Semi-Bold) and 700 (Bold)
  • Base Line Height: 1.65 (ensuring optimal readability and WCAG accessibility)

5. Technical Accuracy & Standards Compliance (Q5)

In accordance with Question 5(a), all HTML5 and CSS3 documents have been rigorously verified against the official W3C Markup and CSS Validation Services (https://validator.w3.org/).

  • HTML5 Semantic Well-Formedness: All documents feature standard <!DOCTYPE html>, language declarations, closed semantic tags, valid meta tags, accessible image alt attributes, and no deprecated elements.
  • CSS3 Conformance: style.css utilizes valid CSS Custom Properties (Variables), strictly supported syntax, and valid media queries.
  • Zero JavaScript / Zero Framework Policy: Zero <script> tags, zero inline JavaScript events, and zero prohibited CSS/JS frameworks. Only authorized Google Fonts and Google Materials are incorporated.
